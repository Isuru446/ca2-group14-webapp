What Is Cloud Computing?

Cloud computing means using computing services such as storage, servers, and software through the internet instead of running everything on your own computer.

Types of Cloud Services

  • IaaS: Rent virtual servers, storage, and networks.
  • PaaS: Use a ready-made platform to build and deploy applications.
  • SaaS: Use software online without installing or managing its servers.

Cloud tip: Azure Static Web Apps can host a website made with HTML, CSS, and JavaScript.
